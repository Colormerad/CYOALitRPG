Loading Icon Usage

Use the new .loading-icon component for consistent loading animations:

Basic Usage:

<!-- Simple loading icon -->
<div class="loading-icon medium"></div>

<!-- Loading container with text -->
<div class="loading-container">
  <div class="loading-icon large"></div>
  <div class="loading-text">Loading...</div>
</div>

<!-- Full-screen loading overlay -->
<div class="loading-overlay">
  <div class="loading-container">
    <div class="loading-icon extra-large"></div>
    <div class="loading-text">Please wait...</div>
  </div>
</div>

Size Variants:

  • .loading-icon.small - 1x scale (16px)
  • .loading-icon.medium - 2x scale (32px)
  • .loading-icon.large - 3x scale (48px)
  • .loading-icon.extra-large - 4x scale (64px)

Speed Variants:

  • .loading-icon.slow - 3 seconds per cycle
  • .loading-icon - 2 seconds per cycle (default)
  • .loading-icon.fast - 1 second per cycle
  • .loading-icon.ultra-fast - 0.5 seconds per cycle

Customizable Animation Usage

For custom animations, use the .obj-sprite-animation class with CSS custom properties:

<div class="obj-sprite-animation sprite-2x" 
     style="--sprite-row: 11; 
            --sprite-start-col: 14; 
            --sprite-end-col: 25;
            --sprite-duration: 2s;"></div>

Available Properties:

  • --sprite-row: Which row to animate (0-based)
  • --sprite-start-col: Starting column (0-based)
  • --sprite-end-col: Ending column (0-based, inclusive)
  • --sprite-duration: Animation speed (e.g., 2s, 500ms)
  • Animates from start-col to end-col (inclusive) - up to 20 frames supported

Static Sprite Usage

For non-animated sprites, use the existing system:

  • SCSS: Add entries to $object-sprite-icons map in global-components.scss
  • TypeScript: Add entries to OBJECT_ICON_ENTRIES array in icon-catalog.ts
  • HTML: Use classes like .obj-sword or utility classes like .obj-r0-c0

Quick Reference

Sprite Sheet Specs:

  • Size: 1024x1024px
  • Icon size: 16x16px
  • Spacing: 8px between icons
  • Offset: 17px from top-left corner
